📝 About This Project

This project is a full-stack e-commerce platform designed with a focus on performance, user experience, and modern design patterns. It features real-time inventory updates, a smooth checkout flow with Stripe integration, and a comprehensive admin dashboard.

The front-end is built with React and styled using TailwindCSS for a responsive, mobile-first design. The back-end uses Node.js with Express, and MongoDB for the database layer. Authentication is handled with JWT tokens and includes social login options.

Key features include product search with filters, wishlists, order history, and real-time notifications for order status updates via WebSockets.
